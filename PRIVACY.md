# Privacy Policy — RoB NFC tag reader

**Effective date:** 29 July 2026  
**Last updated:** 29 July 2026

RoB NFC tag reader is designed to read NFC tags containing person names, maintain a session list, and export that list to an Excel-compatible `.xlsx` file.

## Data handled by the app

The app may process the following information when you use it:

- the text stored on an NFC tag, normally a person's name;
- the NFC tag identifier used to prevent an immediate duplicate callback from the same tag;
- the date and time of a scan;
- session status and locally stored session history.

## Local processing

This information is stored only in the app's local database on the Android device. The app does not include advertising, analytics, user accounts, tracking SDKs, or an Internet permission. It does not transmit names, tag identifiers, scan times, or session history to the developer or to third parties.

Android backup is disabled for the app's local database in the Google Play candidate.

## Excel exports

An Excel file is created only when the user selects **Finish for Today**, chooses a destination, and confirms the save operation. The file is written to the location selected by the user through Android's document picker.

If the user chooses a cloud-storage provider, that provider may receive and process the exported file according to its own privacy policy. RoB NFC tag reader does not automatically upload exported files.

## Permissions

- **NFC:** required to read NFC tags.
- **Vibration:** used only to confirm that a name was successfully added to the live list.

## Data control and deletion

Users can remove individual entries from the review screen. Uninstalling the app removes the app's local database. Exported files remain in the storage location selected by the user and must be deleted there separately.

## Children

The app is intended as an operational tool for event or attendance staff and is not directed to children.

## Changes to this policy

This policy may be updated if the app's features or data practices change. The effective date and last-updated date will be revised when material changes are made.
