# Support — NFC to Excel tag reader

NFC to Excel tag reader is an offline Android utility for reading NFC tags and exporting daily sessions to Excel.

## Before reporting a problem

Please include:

- app version
- phone manufacturer and model
- Android version
- whether NFC is enabled
- a clear description of what happened
- screenshots of any error message

For Excel export problems, also mention the selected save provider, such as internal storage, Google Drive, or OneDrive.

## Public project page

https://github.com/ampetre/nfc-people-read

Use the repository’s issue-reporting facilities for bug reports and feature requests. Do not include real names, private NFC data, passwords, or sensitive exported files in a public report.

## Data recovery note

Do not uninstall the app while an important unexported session is still stored locally. Uninstalling removes the app’s local database.
